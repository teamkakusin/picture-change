# picture-change
---
Picture Change は、ブラウザ上で動作するシンプルな画像編集ツールです。ドット化（ピクセル化）、色数変更（簡易量子化）、解像度変更、VHS 風フィルターをサポートしています。

## 使い方
---
1. リポジトリを GitHub に配置します（既にこのリポジトリにファイルを追加しています）。
2. GitHub Pages を有効化します（Settings → Pages → Source → Branch: `main` / Folder: `/ (root)` を選択）。
3. ページが公開されたら、ブラウザから画像をアップロードして各種スライダーで調整します。

## ファイル
---
- index.html — UI
- style.css — スタイル
- app.js — 画像処理ロジック
- README.md — このファイル

## 注意

- 色数変更は軽量なビット削減アプローチを使っており、厳密に指定した色数になるとは限りません。高速性を優先しています。
- 大きな画像は自動的に 2048px までリサイズして処理します。
